PortuPrep Cards — iOS build on Mac
===================================

Repos:
  Web app:  https://github.com/postal888/Port_mob
  iOS shell: https://github.com/postal888/portmob_ios

--- First time on Mac ---

  git clone https://github.com/postal888/Port_mob.git
  cd Port_mob
  rm -rf ios
  git clone https://github.com/postal888/portmob_ios.git ios
  cd ios
  chmod +x mac-build.sh
  ./mac-build.sh

Same as Android: web build → cap sync → native IDE (Xcode instead of Android Studio).

--- Updates ---

  cd Port_mob && git pull
  cd ios && git pull
  ./mac-build.sh

--- Manual steps (equivalent) ---

  cd Port_mob
  npm ci
  npm run build:ios
  cd ios/App && pod install
  cd ../.. && npx cap open ios

Bundle ID: com.portuprep.cards

Files in this repo:
  package.json              Capacitor plugins for iOS
  App/App/capacitor.config.json
  mac-build.sh              one-command Mac build

Web assets (App/App/public) are generated by npm run build — not stored in git.

--- Windows: push iOS shell updates ---

  cd Port_mob
  npm run build:ios
  npm run push:ios
